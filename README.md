# Витан-К: программа просчета мебели

Локальный прототип для ПК: проекты, изделия, деталировка, карта кроя, себестоимость, зарплата и экспорт.

## Запуск

```powershell
npm start
```

После запуска откройте:

```text
http://127.0.0.1:4173
```

Данные сохраняются в браузере через `localStorage`. На главном экране есть кнопки сохранения и загрузки базы в JSON.

## Что уже есть

- создание проектов с контрагентом и адресом;
- список изделий внутри проекта;
- карточка изделия с изображением, габаритами, ножками и деталями;
- материалы по типам: ЛДСП, Фурнитура, Кромка, Прочее;
- себестоимость по м², погонным метрам или штукам;
- формулы размеров деталей вроде `длина изделия - 32` и `глубина изделия`;
- зарплата произвольной суммой или по квадратуре выбранных изделий;
- карта кроя ЛДСП с настройкой зазора, подрезки и перетаскиванием деталей;
- экспорт деталировки в Excel-совместимый `.xls`;
- печать/сохранение карты кроя в PDF через системное окно печати.
