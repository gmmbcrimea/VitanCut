# Сборка Vitan-Cut для Windows

Исходники продолжают редактироваться в текущей папке. Electron используется как desktop-оболочка и для выпуска установщика.

## Разработка

- `npm start` - обычная web-версия на `http://127.0.0.1:4173`.
- `npm run desktop` - desktop-версия из текущих исходников.

В режиме разработки файловая база находится в `data/database.json` текущего проекта.

## Windows-сборка

1. Один раз установить зависимости: `npm install`.
2. При необходимости обновить `version` в `package.json`.
3. Выполнить `npm run dist:win`.
4. Готовый NSIS-установщик появится в `dist/`.

Текущая сборка:

- приложение называется `Vitan-Cut`;
- разработчик указан как `Mikey Snow`;
- открывается в отдельном окне без браузерной панели;
- само поднимает локальный сервер на свободном порту;
- создает ярлыки на рабочем столе и в меню "Пуск";
- использует логотип как иконку приложения и установщика;
- хранит базу в `data/database.json` рядом с установленным EXE;
- сохраняет изменения сразу и повторно при закрытии окна.

Закрепление в панели задач выполняется штатной командой Windows "Закрепить на панели задач" у запущенного приложения или ярлыка в меню "Пуск".

Для следующей упаковки достаточно снова выполнить `npm run dist:win`.
