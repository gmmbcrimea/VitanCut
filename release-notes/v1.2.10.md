# VitanCut 1.2.10

- При запуске добавлено стартовое окно с логотипом по центру, сменяющимися статусами и индикатором загрузки. Минимальное время показа — 2,5 секунды.
- При создании деталировки и построении раскроя отображаются аналогичные окна с уменьшенным логотипом. Результат открывается не раньше чем через 3 секунды и после завершения расчёта.
- Для деталировки добавлены защита от повторного нажатия и сообщение об ошибке. При сбое запуска сохраняется возможность восстановления приложения.
