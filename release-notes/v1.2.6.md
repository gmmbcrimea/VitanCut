# VitanCut 1.2.6

- В настройках внешнего вида добавлен переключатель «Фон окна Acrylic».
- При включении основная область окна получает системное размытие фона, а поля и списки сохраняют читаемость.
- Переключение работает без перезапуска; выбор сохраняется локально и не заменяется при облачной синхронизации.
- При выключении, отключённых эффектах Windows или высокой контрастности используется непрозрачный фон.

Для существующих баз Acrylic по умолчанию выключен. База и остальные настройки сохраняются.
