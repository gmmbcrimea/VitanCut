# VitanCut 1.3.1

- В режиме каталога «По группам» добавлена кнопка «Создать группу». Пустые группы сохраняются локально после перезапуска.
- В окне группировки выбранных изделий добавлена кнопка создания новой группы. Добавлена проверка пустых и повторяющихся названий.
- Из контекстного меню изделия каталога убран пункт «Добавить».
- Главное окно запоминает размер, положение и развёрнутое состояние. При следующем запуске окно восстанавливается, включая обычные размеры для выхода из развёрнутого режима.
- Параметры окна сохраняются локально, отдельно от базы и облачной синхронизации, в том числе перед перезапуском для установки обновления. Повреждённый файл параметров не блокирует запуск.

Важно для администратора облака: синхронизация пустых групп изделий между компьютерами требует применения миграции `supabase/migrations/2026102701_product_groups.sql`. Миграция проверена на локальной изолированной базе; публикация этого релиза не применяет её к рабочему Supabase автоматически.
