# VitanCut 1.2.7

- Исправлено применение обновлений в папках с пробелами, кириллицей и завершающим разделителем пути в Windows PowerShell 5.1.
- Помощник запускается непосредственно из файла, без ограниченной по длине команды cmd.exe. Приложение ожидает подтверждение его запуска перед закрытием.
- Неполная резервная копия больше не используется для отката. Если резервное копирование не удалось, текущая версия остаётся на месте и запускается снова.
- Добавлены реальные проверки выполнения помощника обновления, сохранности базы и отказа резервного копирования.

Если обновление из старой версии уже не применяется, установите этот релиз вручную один раз, сохранив папку data. Следующие обновления выполняет исправленный помощник.
