# VitanCut 1.3.0

- Добавлена автоматическая проверка обновлений при запуске приложения. Проверка работает в фоне, независимо от восстановления облачной сессии; при наличии новой версии появляется уведомление.
- Сохранены ручная проверка обновлений и автоматическая проверка каждые 30 минут. Исключены одновременные запросы проверки; таймаут подключения обрабатывается без аварийного завершения.
- В формулах размеров деталей добавлен оператор степени `^`: например, `длина изделия^2`. Степень имеет приоритет перед умножением; цепочки степеней вычисляются справа налево.
- Добавлена функция квадратного корня `sqrt(...)`, включая вложенные выражения, размеры изделия и ссылки на другие детали.
- Добавлена диагностика некорректных степеней, корня из отрицательного числа и чрезмерно вложенных выражений.
