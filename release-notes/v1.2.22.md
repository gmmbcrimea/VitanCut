# VitanCut 1.2.22

- Группы в каталоге материалов теперь свёрнуты по умолчанию. Вручную раскрытые группы сохраняют своё состояние при сохранении материала.
- Группы всегда расположены вверху списка, в алфавитном порядке, независимо от выбранного режима сортировки материалов.
- Сортировка по названию А–Я, Я–А или дате добавления применяется внутри каждой группы и отдельно к материалам без группы, расположенным ниже.
