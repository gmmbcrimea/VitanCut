# VitanCut 1.3.19

- Улучшено сглаживание миниатюр изделий: изображения подготавливаются под размер отображения с учётом масштаба Windows.
- Новая обработка применяется и к ранее сохранённым картинкам без повторной загрузки и изменения исходных данных.
- Добавлен ограниченный кэш превью и фоновая обработка изображений для уменьшения повторных вычислений.
- Новые изображения сохраняются с разрешением до 1024 пикселей; открытие карточки больше не уменьшает сохранённое изображение повторно.
