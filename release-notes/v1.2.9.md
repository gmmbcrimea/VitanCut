# VitanCut 1.2.9

- В каталоге изделий перед названием отображается миниатюра изображения из карточки изделия.
- В карточке изделия список выбора материала разделён по категориям из каталога материалов. Поиск по названию и категории сохранён.
- Исправлена потеря текстуры при сохранении материала. Изображение сохраняется для листовых, погонных и штучных материалов независимо от категории.
