# VitanCut 1.2.14

- При сохранении изделия детали автоматически сортируются по типу материала: пиломатериалы, фурнитура, кромка, затем остальные категории по алфавиту.
- Внутри одной категории сохраняется текущий порядок деталей. Формулы, ссылки на детали и назначения кромки остаются без изменений.
- Сортировка применяется к сохраняемой копии изделия в проекте и каталоге, не переставляя строки во время редактирования.
