# VitanCut 1.2.23

- В карточке изделия при выборе материала детали внутри категорий отображаются группы из каталога материалов.
- Группы свёрнуты по умолчанию и расположены перед материалами без группы.
- Поиск учитывает названия материалов, категорий и групп, автоматически раскрывая подходящие категории и группы.
- В списке сохранены цена, единица измерения и кнопка «Добавить» внизу каждой категории.
