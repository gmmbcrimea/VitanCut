# VitanCut 1.3.4

- Багфикс: устранены устаревшие контуры подсветки при прокрутке списков. Во время движения списка контуры скрываются и восстанавливаются после остановки по актуальным координатам.
- Оптимизировано обновление подсветки в карточках изделий с большим количеством деталей: частые запросы объединяются, повторный обход цепочек родительских элементов исключён.
- Добавлена изолированная диагностика обновления подсветки и расчётов карточки для поиска задержек. В обычном режиме профилирование отключено.
- Формулы, расчёт стоимости и форматы пользовательских данных не изменены.
