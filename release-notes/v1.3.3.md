# VitanCut 1.3.3

- Кнопка «Добавить ЗП» сразу открывает форму начисления. Строка создаётся только после сохранения; отмена не добавляет пустую запись.
- В строках ЗП за м² теперь показаны комментарий, ставка, площадь проекта и итоговая сумма. Итог пересчитывается при изменении площади, с сохранением существующей логики расчёта.
- Для фиксированной ЗП отображаются комментарий, тип начисления и сумма. Длинные комментарии переносятся на следующую строку.
- В форме начисления добавлены понятная подпись ставки за м², проверка введённой суммы и защита от повторного открытия диалога.
- Показатель «Себестоимость материалов» переименован в «Стоимость ЛДСП» без изменения расчёта. Обновлены переводы интерфейса.
