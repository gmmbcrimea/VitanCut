# VitanCut Installer 1.1.1

- Обновлены кнопки, флажки, поле пути и типографика установщика.
- Добавлен системный материал окна: Mica в поддерживаемых Windows 11, Acrylic в Windows 10. При отключённой прозрачности используется обычный фон.
- Исправлены масштабирование DPI и размещение элементов на небольших экранах.
- Установщик выбирает последнюю стабильную версию приложения, пропуская релизы установщика, тестовые версии и файлы контрольных сумм. На момент выпуска это VitanCut 1.2.5.
- В списке приложений Windows отображается версия установленного приложения.
- Деинсталлятор удаляет только перечисленные установленные файлы, сохраняя локальную базу и посторонние пользовательские файлы.

Издатель: GMMB. Папка по умолчанию: Документы\VitanCut. Размер EXE меньше 1 МБ.
Автоматическое закрепление на панели задач зависит от разрешений Windows; при необходимости закрепите ярлык вручную.
