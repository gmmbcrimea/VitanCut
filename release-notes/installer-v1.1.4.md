# VitanCut Installer 1.1.4

- Деинсталлятор удаляет фоновую задачу проверки Supabase перед удалением файлов программы.
- Удаляется только задача текущего пользователя, которая запускает проверку именно из удаляемой установки. Задачи других копий VitanCut не затрагиваются.
- Запущенная проверка останавливается перед удалением задачи. Если очистка не удалась или превысила 30 секунд, удаление программы отменяется до изменения файлов и регистрации приложения.
- Сохранена совместимость со старыми установками, в которых фоновой задачи нет. База и пользовательские файлы сохраняются.
- Обновлены проверки очистки для PowerShell 5.1 и 7. Размер установщика остаётся меньше 1 МБ.
