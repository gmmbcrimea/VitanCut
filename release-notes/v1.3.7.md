# VitanCut 1.3.7

- В списке изделий проекта рядом с количеством добавлена стоимость одной единицы: материалы с учётом цен проекта и допуска на обрезки плюс ЗП за площадь этого изделия. Фиксированная ЗП проекта в цену единицы не включается.
- В автоматически сформированной строке кромки теперь можно выбрать другой материал из категории «Кромка» с единицей измерения «пог. м».
- Замена кромки применяется ко всем использующим её деталям текущего изделия с сохранением выбранных граней. Метраж и стоимость пересчитываются сразу; если новая кромка уже используется, автоматические строки объединяются.
- Ручные строки кромки и другие изделия не изменяются.
