# VitanCut 1.2.0

- Улучшена надежность сохранения базы: изменения базы и состояния синхронизации сохраняются согласованно и восстанавливаются после прерывания записи.
- Облачные операции выполняются последовательно; исправлены зависание при входе, обработка обновления сессии и загрузка больших списков изменений.
- Открытые редакторы сохраняют изменения по идентификатору объекта после синхронизации. Копирование изделия сохраняет связи формул между деталями.
- Настройки оформления остаются локальными; облачные изменения не заменяют тему и другие параметры интерфейса.
- Улучшено завершение приложения во время синхронизации и обработка ошибок фоновых операций.
- Снижены временные выделения памяти при построении раскроя, сохранены правила размещения и поворота деталей.
- Исправлена обработка EXIF-ориентации изображений и квадратных текстур материалов; сохранено качественное сглаживание.
- Обновлены зависимости экспорта для устранения известных уязвимостей.
- Укреплено сохранение пользовательских данных при обновлении и откате программы.
- В release-публикацию включены ресурсы XAML, необходимые для запуска окон. Сборка содержит .NET runtime.
