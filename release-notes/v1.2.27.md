# VitanCut 1.2.27

- При сохранении деталировки, раскроя и сводной таблицы в имя файла автоматически включаются тип отчёта, название проекта и текущие дата и время.
- Дата берётся при нажатии «Сохранить», а не из даты создания проекта или расчёта. Формат имени: `Тип отчёта_Название проекта_ГГГГ-ММ-ДД_ЧЧ-мм`.
- Из названия проекта заменяются недопустимые для имени файла символы; слишком длинные названия сокращаются.
- Единый формат имён применяется к доступным вариантам экспорта в PDF и Excel.
