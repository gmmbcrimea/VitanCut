# VitanCut 1.3.6

- В каталоге материалов добавлено перетаскивание одного или нескольких выделенных материалов между группами своей категории. Группа назначения подсвечивается; перенос возможен и в свёрнутую группу.
- Багфикс: при смене материала кромки уже выбранные грани сохраняются. Метраж и стоимость сразу пересчитываются по новой кромке без повторного выбора граней.
- В списке изделий проекта количество отображается справа в отдельной колонке. Под названием оставлены габариты без дублирования количества.
