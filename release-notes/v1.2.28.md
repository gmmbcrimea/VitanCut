# VitanCut 1.2.28

- В каталоге изделий добавлены режимы «По заказчикам» и «По группам» с сегментированным переключателем.
- Добавлен общий поиск изделий по названию, заказчику и группе. Результаты показываются вместо двух колонок, с изображением и именем заказчика.
- Изделия можно объединять в группы через контекстное меню с выделением Ctrl/Shift. Группа не меняет заказчика; существующие изделия по умолчанию находятся в разделе «Без группы».
- Добавлено перетаскивание между заказчиками с выбором копирования или перемещения, а между группами — перемещение. Цель переноса выделяется акцентной рамкой и фоном без сдвига строки.
- Кнопка информации открывает изображение, краткую деталировку, заказчика, группу, дату создания и сведения об использовании изделия в проектах. Для старых изделий без сохранённой даты отображается «Неизвестно».
- В меню «Добавить изделие» проекта добавлены сегментированные режимы «Этот заказчик», «Все заказчики» и «По группам». Списки заказчиков и групп свёрнуты по умолчанию.
- Обновлены строка поиска с лупой и круглые кнопки информации; устранены обрезание значков и двойной круг вокруг значка информации.
- Новые элементы интерфейса переведены на поддерживаемые языки. Группы и сведения об изделиях сохраняются локально и при облачной синхронизации.
