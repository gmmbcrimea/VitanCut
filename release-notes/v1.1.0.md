## Что нового в VitanCut 1.1.0

- Добавлено аварийное окно с описанием ошибки при запуске.
- Из аварийного окна можно повторить запуск или восстановить предыдущую версию.
- Перед установкой обновления автоматически сохраняется резервная копия текущей версии.
- В материалах исправлена ширина столбцов и добавлена группировка через множественное выделение.
- Установщик регистрирует VitanCut в списке приложений Windows и добавляет удаление программы.
