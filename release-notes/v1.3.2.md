# VitanCut 1.3.2

- Добавлена фоновая проверка доступности Supabase через Планировщик Windows раз в три дня. При запуске приложение проверяет задачу и создаёт или восстанавливает её при необходимости.
- Проверка запускается без окон приложения, не читает пользовательскую базу и токены, не изменяет данные и не отмечает синхронизацию успешной. Результат сохраняется в локальном журнале.
- Задача работает от текущего пользователя без сохранения пароля и повышения прав, учитывает пропущенные запуски и повторяет неудавшиеся проверки. Для выполнения пользователь должен быть в системе, ПК включён и подключён к сети.
- Добавлена безопасная серверная функция проверки доступности. Миграция применена к рабочему Supabase; пользовательские таблицы не изменялись.
- Категории материалов, заказчики и группы изделий приведены к единому стилю: одинаковые отступы, скруглённое выделение и акцентная полоска слева. Сохранена отдельная подсветка цели перетаскивания.

Проверка раз в три дня не гарантирует защиту бесплатного Supabase от паузы и не возобновляет уже приостановленный проект. Для автоматического удаления фоновой задачи вместе с программой используйте обновлённый установщик 1.1.4.
